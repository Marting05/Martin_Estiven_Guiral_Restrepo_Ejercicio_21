# Martin_Estiven_Guiral_Restrepo_Ejercicio_21

Ejercicio 21 – Parqueadero

Un parqueadero registra los vehículos que ingresan durante el día. De cada vehículo se conoce la placa, tipo de vehículo, nombre del propietario y valor pagado.

El administrador necesita conocer cuál fue el vehículo que generó el mayor pago durante la jornada.

Desarrolle una solución que permita identificarlo y presentar la información correspondiente.
